# RimWorld mods by Bolek98

Source code of my RimWorld 1.6 mods published on the Steam Workshop.

| Mod | Version | Folder |
|---|---|---|
| Smart Colonist Gear | 2.13.0 | [SmartColonistGear](SmartColonistGear) |
| World at Your Level | 2.13.0 | [WorldAtYourLevel](WorldAtYourLevel) |
| Evergrowth | 1.7.0 | [Evergrowth](Evergrowth) |

Each folder is a complete mod (About, Assemblies, Defs, Languages, Source) with its `CHANGELOG.txt`.
All mods need [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077).

Bug reports and ideas are welcome in the Issues tab or in the Workshop comments.
