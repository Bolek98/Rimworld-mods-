# RimWorld mods by Bolek98

Source code of my RimWorld mods (RimWorld 1.7).

## Branches
- **main** – the versions released on the Steam Workshop.
- **dev** – the versions in testing (newer, may still have bugs).

Bug reports and ideas are welcome in the Issues tab or in the Workshop comments.
