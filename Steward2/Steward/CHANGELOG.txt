3.0.5
- Work no longer swaps back and forth between two colonists on every plan: whoever already does a work keeps it unless somebody is clearly better, equal colonists always end in the same order
- A colonist could end up without any top job (priority 1) during a crisis or a focus – fixed
- A downed, anaesthetized or blinded colonist no longer loses all his work; it stays as it was until he is up again
- Keyz' Allow Utilities urgent hauling and finishing off are treated as urgent work (like firefighting)
- Crisis rules for hauling no longer pull in unrelated no-skill work types (priority cleaning, power generation, recycling …)
- If the base plan fails, the priorities stay untouched instead of a half-empty plan being written
- The log lists up to 60 changes per plan and says how many more there were

3.0.4
- Settings: new "Report a bug" button (bottom left) – a short report for a Workshop comment and a full one for GitHub Issues, with this mod's errors, the mod list and other mods that change the same game code. Nothing is sent anywhere by itself.
