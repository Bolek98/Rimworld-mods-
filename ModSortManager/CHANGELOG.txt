0.1.9

- New "Workshop" button opens the Steam Workshop inside the game (Steam overlay); mod pages and requirement links open there too, so you don't have to leave the game.

0.1.8

- "Do the same thing": pairs where a mod can block the other get buttons to turn off one of them.

0.1.7

"How they change it" lists every shared method (thanks ColossalFossil).
- Mod details: what the mod requires (✓ active, ○ installed but not active, ✗ missing) and which active mods need it.

0.1.6

0.1.5
- New "Restart" button next to Close when the mod list has not changed: restarts the game without touching the mod list (the return to the game works the same as when saving)
- What's new: after an update a window shows once what changed (together with Bolek98's other mods; can be turned off)

0.1.4
- Settings: new "Report a bug" button (bottom left) – a short report for a Workshop comment and a full one for GitHub Issues, with this mod's errors, the mod list and other mods that change the same game code. Nothing is sent anywhere by itself.

=== Workshop release 0.1.3 (23 Oct 2026) – everything since the previous Workshop version ===
0.1.3
- New: Check before saving. When you save a changed mod list, Mod Sort Manager first looks for missing dependencies, new mods made only for older game versions, many new mods at once and things new mods need (build costs, recipes) that will not exist after the restart – the kind of error that makes the game reset your whole mod list. Fix it with one click, add only the first group of new mods (after the restart Mod Sort Manager offers the next group), or save anyway. Can be turned off in the settings.

Mod Sort Manager 0.1.3
======================
- New: Check before saving. When you save a changed mod list, Mod Sort Manager first looks for missing dependencies, new mods made only for older game versions, many new mods at once and things new mods need (build costs, recipes) that will not exist after the restart – the kind of error that makes the game reset your whole mod list. Mod Sort Manager 0.1.2
======================
- New: Find the faulty mod (Problems tab). The game crashes or throws errors and you don't know why? Mod Sort Manager disables half of the suspect mods and restarts; you answer "still there / gone" in a small window in the main menu and it halves again – about 8 restarts for 200 mods. Libraries, DLCs and the game stay on, the error count since loading is shown, and your list is restored exactly at the end. It also checks that each step really loaded (a load error makes the game fall back) so a wrong answer can't spoil the result.
- New: Order guard. After a start, Mod Sort Manager checks the mod list is the same as you last saved it. If another program, an update or the game changed it (e.g. the game resetting the list after a load error), you see what moved, was added or is missing, and restore your order with one click. Uninstalled mods and newly added DLCs don't raise a false alarm. Can be turned off in the settings.
- New: Mods added in the last 7 days get a NEW tag and sit at the top of the inactive list (newest first). The date each mod was added is shown in its details and tooltip.
- New: "Problems only" filter in the active list.
- If one patch fails (another mod or a game update), the rest of Mod Sort Manager keeps working.

Mod Sort Manager 0.1.0
======================
- First release.
- The game's Mods button opens Mod Sort Manager (the original window is one click away).
- Load order: inactive and active lists, search, drag and drop, move to top / bottom.
- Smart sort: mods' own load rules and dependencies, Harmony first, Core and DLCs before other mods, your order kept where possible.
- Problems: duplicate mod folders, missing dependencies, incompatible mods, wrong load order, mods for older game versions, mods doing the same thing (Harmony patch estimate).
- Keep the newer copy of a duplicate with one click (the other copy is moved to a backup folder, Workshop copies are unsubscribed).
- Profiles: save and load mod lists (the game's own mod list files).
- Backup of ModsConfig.xml before every save (last 20), restore with one click.
- Save and restart without quitting; optionally load the last save after the restart.
- Optional Esc menu entry in a game (off by default): saves, restarts and returns you to your colony.
- Steps aside when Fluffy's Mod Manager is active.
- RimWorld 1.7 supported (works on 1.6 too).
