Smooth FPS 1.2.1
================
- New: Smoothness at every speed. The simulation budget works at 1× to 4×, and each speed can have its own target FPS and simulation limit (Smoothness tab → By game speed) – e.g. a smooth 90 FPS at 1× and more game speed at 4×. By default every speed uses the common settings, so nothing changes until you set it.
- Fix: on 1.7 "Unload unused textures" could drop textures the game still uses – icons in the Architect menu turned into empty squares. The option is now off and hidden on 1.7 (it is still there on 1.6).
- Fix: a short moment when game time stood still (a hitch, another mod) could switch the smoothness budget off until the next restart – at 4x the game then ate the whole frame (high TPS, FPS under 20). Now it only counts when the game really tried to tick, steps aside for 20 s and tries again; it stays off only after 3 such stalls.

Smooth FPS 1.2.0
================
- New tab: Memory & freezes – Fewer Freezes is now part of Smooth FPS. Two modes picked by the game version itself: on 1.7 (.NET) memory is cleaned in the background and big clean-ups that stop the game are avoided during play ("smooth play" low-latency mode, background clean-ups while paused and after saving, optional compaction during long pauses); on 1.6 and older the proven per-frame clean-up and big clean-ups while paused. Freeze meter, memory display and a low-memory warning included. Turn the old Fewer Freezes mod off – the tab steps aside while it is active.
- New: What slows the game (Smoothness tab). Measures for 30 seconds at the speed you play – also 4× with Smart Speed – and shows the 10 slowest mods and the 10 slowest things or functions (ms per second). Each millisecond is counted once, for the deepest mod it ran in. The measuring is added only while it runs and removed afterwards.
- New: Performance report in one click – your PC, map, FPS/TPS, settings, the last benchmark and "what slows the game" in one text. Copy it into a Workshop comment or save it to a file.
- New: Smart FPS target (on by default). When the PC can't hold the target for a while, it lowers itself step by step (90 → 75 → 60) so the game keeps a steady rhythm, and climbs back when there is room.
- New: High-speed mode for 4× and faster (on by default): even fewer effects, alerts checked every 4th frame, no weather overlay drawing. Optional and experimental: spread map rebuilds at 4×+.
- Benchmark now runs at the speed you play (4× too) instead of always 3×, and shows the speed in the result.

Smooth FPS 1.1.4
================
- Compatibility: when another mod also takes over the game's tick loop (for example Butter++ or Multiplayer), the simulation budget now steps aside by itself – no more frozen colonists. The Smoothness tab says which mod it is. Everything else keeps working.

Smooth FPS 1.1.3
================
- Safety net: if game time stops moving although the game is not paused (another mod that also takes over the tick loop), Smooth FPS switches its simulation budget off by itself after 3 seconds and the game's own tick loop is used again. A warning in the log says so.
